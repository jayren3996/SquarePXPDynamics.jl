# Agent Instructions

Before substantial work, read `notes/README.md`, `notes/project_goals.md`, and
`notes/methodology/revival-validation.md` (the load-bearing validation lesson).

Durable knowledge lives in `notes/` (the single source of truth) — there is NO
separate "memory" layer. Record findings, conventions, and decisions in the
relevant `notes/<subfolder>/` file: edit the topical note in place when a
conclusion changes, keep dated experiment records alongside, and move superseded
notes to `notes/archive/`. See `notes/workflow/knowledge-organization.md`.
